## 👨‍💻 Sobre mim

Sou estudante de **Engenharia de Software na Unicesumar**, atualmente cursando o **6º semestre**, com interesse em desenvolvimento Front-End, construção de sistemas e soluções tecnológicas.

Busco aprimorar continuamente meus conhecimentos por meio de projetos acadêmicos e pessoais, aplicando conceitos de programação, banco de dados e engenharia de software.

Tenho também conhecimentos em **Engenharia de Requisitos**, incluindo levantamento, elicitação, análise, documentação e modelagem de requisitos, buscando compreender as necessidades dos usuários e transformá-las em soluções eficientes.

🎯 Meu objetivo é crescer profissionalmente na área de desenvolvimento de software, contribuindo para projetos que unam tecnologia, funcionalidade e boas práticas de desenvolvimento.
